# 用户要求追踪

此文档记录本技能如何保留制作过程中形成的要求，方便维护者检查修改是否丢掉原意。

| 制作要求 | 技能中的落点 |
| --- | --- |
| 一分钟以内，后来收紧到55秒 | 默认54秒、硬上限55秒，最终按媒体时长实测 |
| 必须竖屏 | 9:16、720×1280，不能只在提示词里声明 |
| 西游IP与经典剧情联动 | 依据新骗局选桥段，保留熟悉关系与可理解前情 |
| 原案真实，不能乱编 | 先看权威原文、提取机制，区分拦截／损失／追回 |
| 前3秒钩子，要吸引人 | 反常行为或冲突开场，正文兑现，禁止空喊“高能” |
| 快节奏不等于缩短／删内容 | 同一片长增加容量，压缩无效过场，保留因果与动机 |
| 加快语速、人物紧接对白 | 快而清楚，不压掉字尾或换气，实际音轨验收 |
| 减少空白／空格间隔 | 压缩时间空档，不误删文档标点与换行 |
| 不要太长无声期 | 检查整轨静音和对白间隔，BGM不能掩盖空剧情 |
| 用剧本Skill深度打磨 | short-drama-write强制使用，缺失先下载安装 |
| 分镜与审查Skill也要用 | storyboard与review同样为必需依赖，记录真实使用 |
| 年轻人爱看的画风 | 国风少年漫、2D赛璐璐，不自动切换写实／Q版 |
| 取信更贴西游 | 适用时用常见妖怪的头像账号，不宣称本人参与 |
| 盘缠→仙丹→灵力越来越重要 | 作为同系列可选递进，按新案例机制合理转译 |
| 三打第三化身不使用老翁 | 沿用该版本时用年轻女性假仙使；别的故事不硬套 |
| 虚构天庭执法电话 | 明确虚构，独立可信联络核验，现实渠道另作提示 |
| 图片用Image而非即梦模型 | 图片与关键帧指定Image，缺失不静默换付费工具 |
| 首尾帧、关键帧再生产视频 | 分镜先明确起止，必要时才补尾帧，不机械加产物 |
| Seedance 2.0 Fast VIP、720P | 当前模型规格与参数核实后运行，换模型要说明 |
| 聊天窗悬浮／半透明、文字不乱码 | 字体后期排版，处理原片乱码，检查整个片段遮挡 |
| 剧本未审核不直接跑 | 阶段A先交完整剧本，用户批准后进入生图 |
| 预算和模型都要看得到 | 当前报价、返工预留、总上限、Image费用分别说明 |
| 3000以内授权后直接做完 | 授权内连续完成，不反复确认；超限或新核心改动再问 |
| 不能把提交当完成 | 实际看片、真实文件、声音字幕、完整解码与预算验收 |
| 可发给别人，换诈骗类型复用 | 按案例机制重写；必需技能自动补齐；不携带原账号授权 |

仓库未发布原项目的账户、任务编号、私人路径或媒体文件。原始脚本里的单次失败经验被转为局部验收要点，未强制所有诈骗采用三棒、三付款或同一分镜数。
