# 全自动启动语

## 最短用法：给一个诈骗类型

```text
使用 $xiyou-antifraud-short-drama，诈骗类型：冒充客服退款。
```

此命令主动启动默认全自动方案：Image使用当前可用配额，视频为Seedance 2.0 Fast VIP、9:16、720P；目标54秒、硬上限55秒，国风少年漫；本项目即梦累计提交报价最多3000积分，包含返工。AI自行查证案例、写作、审稿、分镜、生图、选片、视频生成、后期与验收，到最终MP4交付，不逐阶段等人批准。预算或工具需调整时可在启动句说明。

## 自定义更低预算，仍全自动

```text
使用 $xiyou-antifraud-short-drama，诈骗类型：冒充熟人借钱。
即梦累计上限1000积分，其他采用默认全自动要求，持续到成片交付。
```

## 用户主动要求只看剧本时才暂停

```text
使用 $xiyou-antifraud-short-drama，诈骗类型：虚假中奖。
这次只出剧本给我审核，先不要生图或生成视频。
```

此例由用户主动切换局部输出，不能覆盖全自动默认模式。之后用户说按默认方案继续时，从已有稿件接着完成。

下载、安装或阅读示例本身不启动收费任务。仅询问用法也不启动；当前用户主动请求制作后才执行。账号、模型权限、Image能力或平台强制确认缺失时，只请求必要操作，不虚构已完成。
