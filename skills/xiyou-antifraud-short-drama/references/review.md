# 剧本与成片审查

使用`short-drama-review`，本表补充该项目用户偏好；不代替读取审查技能。没有独立审稿人就标自检。

## 剧本审核

- 前3秒能看懂、能留人，后文兑现钩子。
- 西游经典关系、人物动机或必要前情已建立，不突兀进入骗局。
- 新诈骗类型的实际取信方式、风险行为与升级借口有真实来源，未照搬另一个骗局。
- 快节奏增加容量，保留铺垫和关键因果；人物接话有承接，动作与对白并行。
- 受骗者有可信动机，阻止者确实介入，反转与损失能演出来。
- 真实原案、艺术转译、虚构角色与结局边界清楚。
- 完整可审核剧本已交用户；未审不先生成媒体。

## 生成素材与成片

- 模型与画面参数符合当前批准；720×1280、9:16、总时长≤55秒。
- 说话人、台词、道具交付、反派顺序、揭底时机与跨段接缝可理解。
- 先前损失和状态保留，没有法术自动退款／恢复全部损失。
- 中文字体独立排字，无关键乱码、无双层字幕；实际手机观看仍能读清。
- 文字与音轨、交易发生时刻对齐，转写同音错字已校核。
- 脸、手、证据未被聊天框遮住；旧生成字先处理。
- 无长无意义对白空档，整轨无长静音；有BGM但剧情空白的片段单独复查。
- 判断提示若采用，对白继续；视觉按钮未被误称为可点击游戏。
- 可信核验联系方式来源独立，现实行动与虚构天庭渠道区分。
- 媒体可完整解码、有声音；任务终态与真实产物已核对。
- 预算含所有提交和返工，状态不明已预留；报价与账单分开。

## 可选自动检查

从技能目录运行：

```bash
python3 scripts/verify_video.py /实际路径/成片.mp4
```

需要Python、FFprobe与FFmpeg。脚本只做技术检测：时长、尺寸、编码、音轨、解码与低电平静音；不能判断剧情、口型、中文字义、骗局事实或“BGM下发呆”。最终还需按上述条目看片。

修复优先局部处理；不能把核心漏拍当可忽略小瑕疵，也不能因单处尾帧问题把已合格整片全部重生。
