# 西游反诈竖屏短剧

把用户指定的诈骗类型全自动变成可放映的西游反诈短剧。用户主动调用本技能要求制作后，只需提供诈骗类型，其余案例、桥段、剧本、视觉、分镜、选片与后期由AI完成，持续到实际MP4验收并交付。已有稿件或素材时承接进度，不重复生成。

## 默认全自动执行约定

- **默认模式是`automatic`，不设置剧本、人物图、关键帧或选片的人工批准关卡。** 审查不能省略，由写作／分镜／审查技能完成AI内部审查、修改与复核，合格后立即进入下一阶段。
- 当前用户明确启动本技能制作成片时，采用公开启动说明中的默认方案：Image使用其可用配额，视频用指定即梦模型，累计提交报价上限3000积分，含全部返工。首条回复简短告知此范围后开始，不把说明变成“请再次确认”。实际报价仍须查询，费用授权依当前请求、已选择的默认方案与宿主规则记录，不能把模板、安装行为或他人的授权当成当前付费许可。
- 单纯下载／安装、询问技能用法或脱离制作上下文提到诈骗名称不启动收费任务。用户主动调用此技能并提供类型属于制作请求；本轮若已在运行本技能，补充类型后直接继续，不让其重写长授权词。
- 用户明确说“只出剧本”“先给我审核”“不要生图”“先暂停”等，立刻以该限制为准。只有这种明确要求才切换为人工审核或局部输出模式；没有要求时不得沿用旧版双阶段审核。
- 缺少可合理推断的创意偏好时自行选择，不询问桥段、角色、构图或是否继续。只在需要超预算／换收费工具、违反用户锁定要求，或登录／权限／必要人工操作等真实阻塞时请求最少必要决定。不能绕过平台或宿主强制的计费及权限确认。

## 必须保留的制作要求

- 目标54秒，硬上限55秒，9:16，720×1280；国风少年漫、2D赛璐璐质感，面向年轻观众。
- 图片与关键帧使用用户指定的 **Image** 能力；视频默认 **Seedance 2.0 Fast VIP、9:16、720P**。读取当前工具规格与报价，不能静默换模型／平台。
- **快节奏是增加同一时长内的有效内容容量**：压缩对白空档与无效过场，动作、证据和对白并行；保留必要前情、取信过程、关键因果和情感落点，不靠把片子变短、少讲内容或全片倍速冒充优化。
- 前3秒用可理解的冲突／反常行为吸引人；用经典西游画面或一句有用前情建立认知基础，避免开场突兀。反转必须由前文证据和人物选择推动。
- 普通话快而清楚，人物紧接上句；“减少空格／间隔”默认指对白、镜头之间的时间空档，不是删除中文标点、连写文档或取消自然换气。消除空白剧情，不能用BGM伪装连续内容。
- 聊天框／悬浮窗／按钮／字幕由后期中文字体排版；不依赖视频模型造字。原片乱码字幕先修补或覆盖再叠字。
- 受骗者有可信动机，损失与控制权变化实际演出来；阻止者主动核验。真实案例与西游虚构分开，不把虚构灵力支付说成真实案件事实。

用户可以修改默认参数；修改只影响明确指定项，不清空已有约束、稿件和授权。图片工具费用与即梦积分分别说明。

## 0．先安装并读取必需剧本技能

**以下三项为依赖，不是有则用、没有就略过：**

| 技能 | 本工作流中的职责 |
| --- | --- |
| `short-drama-write` | 创作／修订完整剧本、对白、钩子与节奏 |
| `short-drama-storyboard` | 将AI审查合格的剧本落实为分镜与必要首尾帧提示词 |
| `short-drama-review` | 审查剧本、连戏、实际出片与剪辑结果 |

首次使用先读 [依赖安装](references/dependencies.md)。从宿主技能目录检查这三项的真实`SKILL.md`。缺少时，在当前用户授权与宿主规则允许范围内，运行本技能的`scripts/ensure_dependencies.py --install --dest <当前宿主的技能目录>`，只从锁定的公开上游下载缺项，不覆盖已有技能；也可用宿主官方技能安装器安装同一锁定来源。

安装后读取三项的`SKILL.md`再进入对应环节。不能以“效果差不多”为由跳过安装，不能假称已调用。若网络、权限或宿主刷新阻止可用，说明具体阻塞与最少必要操作；可继续整理事实，但不得将未经过依赖技能的稿件标成正式审定稿。安装依赖本身不启动生图或视频；制作范围按当前用户的启动请求与默认执行约定处理。

不要求另起多个智能体；没有独立审稿人时按审查技能自检并如实标“自检”。依赖技能提到“交创作者拍板”或“用户批准”时，创意阶段按当前用户选用的全自动模式，由AI审查与取舍后继续，不新设人工关卡；用户的明确限制、平台计费与宿主权限要求仍须遵守。

## 1．案例与剧本：AI审查通过后继续

先读 [叙事、节奏与西游适配](references/story-and-rhythm.md)。

1. 搜索警方／政府等权威公开案例，阅读原文，记录标题、机构、日期、链接；提取接触入口、取信证据、危险要求、升级借口与真实结局。
2. 按诈骗机制选择西游剧情，不只替换诈骗名，不把所有类型写成同一种返利骗局。不编造受害者、金额、原案对话、警方追回结果；组合多个案例时逐项标来源。
3. 读取并使用`short-drama-write`，写完整时间分段剧本：画面、逐字对白、音效、准确画面文字、转场、道具状态。片长先以目标54秒规划，再试读核对，不按固定字数硬塞。
4. 读取并使用`short-drama-review`，检查钩子、前情、取信、升级、反转、损失递进与防骗落点。修改后复核，保留能吸引人的台词和桥段。
5. 保存案例依据、完整剧本、视觉方向和AI审查结果；发现问题交写作技能修订并复核。**AI审查通过后立即进入分镜与生图，不等待用户回复，不用“是否继续”结束当前工作。** 只有用户明确要求先审稿时，才在该处交稿等待。

## 2．分镜与Image素材

剧本通过AI内部审查后，直接读 [制作、预算与交付](references/production-and-budget.md)，使用`short-drama-storyboard`拆镜。可复制 [图像与视频提示词模板](references/prompt-templates.md)，初始化`assets/templates/`的本项目参数与记录，使用全自动模式配置，区分AI自检状态、当前用户启动请求与费用范围，不能把AI通过写成“用户已审核”，也不能继承他人授权。

先做必要人物、实际出场反派造型与1—3张关键帧；需要精确终点才做尾帧，不为了凑流程每镜出两张。人物板可横向，镜头关键帧优先9:16。引用真实图像，分别写清身份／服装／构图用途；多化身参考不能导致提前揭底或回跳旧造型。

AI检查实际人物图与关键帧，自动修复身份、道具、造型或文字问题。保存实图、分段方案、当前视频报价、返工预留及上限；在当前启动请求覆盖的默认范围内直接提交视频，**不另等用户批准人物图、关键帧、选片或报价**。若当前许可不足、平台强制确认或预计超限，只处理确实缺少的许可。

## 3．连续制作、选片、局部返工与后期

在AI审查合格的创意、当前已允许工具和累计预算内持续完成：按需导入参考、保存稳定任务身份、查询实际模型、分段生成、查看真实产物、局部返工、中文字层合成、混音、导出。不要只提交任务就结束，也不要反复确认同一授权。自行审稿、比较候选与局部改写；不因普通创意选择或存在多个可用候选而停下。登录、必要人工导入、预算超限、收费工具更换或必须违反用户已锁定要求时，只处理真实阻塞。

- 常用生成分组14＋14＋11＋15秒；按当前剧情和模型支持范围调整，不等于全片只有四镜。
- 手机尽量看背面；画面无字幕、聊天字、令牌字和二维码，关键文本交后期。确保说话人、动作、物品交付、变身先后与接缝可理解。
- **已提交与状态不明任务都计预算，包含未入片返工；不预设失败已退款。** 状态不明先查原任务，不换ID重复扣费。
- 每次返工针对具体缺陷；同一方案连续失败两次应改拆镜／参考或后期处理，不无理由持续抽卡。裁切不能删掉关键因果、对白和损失。
- 按真实音轨对齐字幕，转写只辅助定位，同音错字须校正；核心台词发生含义偏差需修复音画，不能用字幕掩盖。
- 四秒判断提示如采用，期间人物继续接话；MP4只演示视觉选项，不能声称已实现交互。真游戏另接事件与止损分支。

## 4．验收并交付

读 [成片审查](references/review.md)，使用`short-drama-review`审查实际素材和成片。用`scripts/verify_video.py`可做技术检测；还要看片识别“有BGM但没有剧情”的空档。仅有成功状态、关键帧、提示词或透明无声叠加层均不算成片。

交付真实可播放MP4（H.264＋AAC、≤55秒、720×1280，默认30fps）、SRT、实际对白时间轴、抽帧预览、案例与虚构说明、包含返工的积分记录。区分提交报价与账户账单扣费，说明真实检查范围与是否自检。
